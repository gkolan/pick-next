# Icebreaker

## What it does

Icebreaker draws a conversation topic from the topic cloud, then picks a person
to answer it. A timer runs for their turn.

## Run one

1. Choose **Icebreaker**.
2. Press **Start** or <kbd>Space</kbd>. A topic is drawn, then a person.
   While the topic is drawn the turn bar stays in place, faded, and reads
   "Picking a topic…".
3. **Pick Next** moves to the next person (and, by default, a new topic).

**Progress** on the left lists each person with the topic they answered.

## Settings

| Setting | Default | What it does |
| --- | --- | --- |
| Topic List | Demo topics | Which list topics are drawn from. |
| Timer Duration (sec) | 120 | Length of each turn (5 to 1200). The demo crew uses 30. |
| New topic each round | On | Off keeps the same topic for the whole session. |
| Allow picking same person again | Off | On lets a person answer more than once. |
| Allow reusing same topic | Off | On lets a topic come up again. |

## Topic lists

**Edit → Edit Topics** changes the current list; **New → New Topics** creates
another. Up to 25 lists of up to 100 topics each. The cloud shows at most 12
topics at a time so it stays readable.
