# Presenting

## Presenter mode

**Present** in the header hides the app chrome and goes full screen, so the
name cloud fills a shared screen or TV. Press **Stop Presenting** or <kbd>Esc</kbd> to leave. During a pick, <kbd>Esc</kbd>
cancels the pick first.

## Keyboard shortcuts

Press <kbd>?</kbd> to show them in the app.

| Key | Action |
| --- | --- |
| <kbd>Space</kbd> | Start / Pick Next |
| <kbd>S</kbd> | Skip current |
| <kbd>P</kbd> | Pause / resume |
| <kbd>E</kbd> | End session |
| <kbd>Esc</kbd> | Cancel pick / exit session |
| <kbd>←</kbd> <kbd>→</kbd> | Change mode when the mode tabs are focused, before starting |
| <kbd>?</kbd> | Toggle help |

Mode and team settings stay fixed during a session. Hot Seat uses its
**Answered** and **Skip** question buttons; the speaker shortcuts apply to
Standup and Icebreaker.

## Theme and sound

The theme button cycles **system → light → dark**; the choice is remembered in
this browser. The speaker button turns sound effects on or off.

## Phones and TVs

The layout works from a 375px-wide phone up to a TV. Name tags scale to fit the
team, and the cloud re-lays out when the window is resized.
