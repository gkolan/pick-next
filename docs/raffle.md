# Raffle

## What it does

Raffle draws a number of prizes from last place up to 1st. Each draw gets a
longer, more suspenseful roulette than the one before, and 1st place gets
confetti. At the end a podium shows the winners.

## Run one

1. Choose **Raffle**.
2. Set Settings → **Number of Prizes** (default 3).
3. Press **Start** or <kbd>Space</kbd>. The draws run on their own, with a short
   pause between each.

Each winner leaves the pool, so every prize goes to a different person. **Winners** on the
left fills in as prizes are drawn (🥇 Gold, 🥈 Silver, 🥉 Bronze, then 4th, 5th…).

## Chances

Each person has 1 to 5 **chances** (Edit → Edit Team, or the chances sticker
under the team name before you start). More chances means more tickets in the
draw. Chances weight every roulette; in Standup they shape the order, since everyone
gets a turn. Extra chances are always visible: the start screen counts them and
the name tags show them.

## The podium

**Raffle Complete** shows the places and the total time. **Run Again** starts a
new draw with the same team.
