# Support

Use the GitHub issue forms for reproducible bugs, feature proposals, and
questions about the guides in `docs/`. Search existing issues first and note
the commit SHA or site URL you are using.

This project is under active development, and replies come as time allows.

For a possible security problem, follow [SECURITY.md](SECURITY.md) to report it
privately. Use the demo team or made-up names in issues, and keep real
colleagues' names, team links, and exported JSON files private.

For a bug, include:

- the commit SHA or deployed URL;
- browser and version, operating system, and screen (laptop, phone, TV);
- whether it happens with the demo team;
- the mode and the exact steps followed; and
- what you expected and what happened.
